# Sources communes

- `registre.md` : sources utilisées dans plusieurs verticales, avec identifiant stable (`[S-INSEE-IP2106]`), URL, date, étiquette.
- `etiquettes.md` : liste des étiquettes d'orientation et leur justification publique.
- `scrutins-selectionnes.md` : la liste gelée des scrutins, choisie avant de regarder les votes (règle dans `01-socle/01-criteres.md` §5). Tant qu'il n'est pas gelé, ce fichier est marqué « proposition ».
- `pdf/` : rapports et documents archivés communs (moins de 20 Mo chacun).

Les sources propres à une verticale restent dans `02-partis/<parti>/`.
